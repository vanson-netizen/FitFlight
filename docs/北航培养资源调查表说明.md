# 北航培养资源调查表说明

对应工作簿：`docs/北航培养资源调查表.xlsx`  
用途：收集学院路、沙河校区运动场地、食堂和菜品的可审计资料，为未来资源匹配库提供人工调查输入。  
限制：调查表不是运行时数据库，不会自动导入小程序；未核实信息不得标记为事实。

## 填写与审核规则

- 浅黄色表头表示必填字段；空白数据行同样使用浅黄色提示必填输入区域。
- 日期统一填写为 `YYYY-MM-DD`。
- `官网已核实` 只用于能由北航官网或学校主管部门页面直接支持的事实，必须同时填写来源和核实日期。
- 现场公告、负责人确认应记录足够的现场说明、部门/岗位和日期；个人口述、论坛、社交媒体只能记为待核实线索。
- 未找到可靠营养来源时，“热量”必须留空，“热量来源”选择“无可靠来源”；不得根据菜名、照片或相似菜品猜测。
- 具体场地开放规则、预约、收费、菜品、价格和供应时间没有可靠来源时保持空白或标记“待核实”。
- 不填写个人敏感信息；“核实人”建议填写项目成员姓名或内部代号，不填写无关人员联系方式。

## 工作表说明

### 使用说明

包含模板用途、颜色图例、状态定义、可靠性顺序和提交前检查。该页不录入资源数据。

### 运动场地

| `capabilityTags` | 机器匹配能力标签，分号分隔 | `walkable_route;open_space` | 是 | 留空，不根据名称推断 |
| 可用器材 | 已确认器材，分号分隔 | `待现场确认` | 是 | 留空 |
| 室内/室外 | 环境类型 | `室内` | 是 | 选“未知/待确认” |

| 是否需要预约 | 预约要求 | `是` | 是 | 选“未知/待确认” |

| 备注 | 限制和疑问 | `开放时间待确认` | 是 | 记录不确定性 |

## 下拉选项

- 校区：学院路校区、沙河校区、未知/待确认。
- 数据状态：草稿、待核实、官网已核实、现场已核实、负责人已确认、已过期、停用。
- 来源类型：北航官网、学校部门公告、场馆/食堂现场公告、负责人确认、供应商文件、包装营养标签、实验室检测、其他待核实线索。
- 餐别：早餐、午餐、晚餐、夜宵、未知/待确认。
- 是/否字段：是、否、未知/待确认。

## 导入前检查

1. 每个 ID 唯一且稳定；
2. 必填字段齐全；
3. 已核实记录具有来源、核实日期和核实人；
4. `verifiedAt/validUntil` 规则已确定；
5. 无营养来源的热量和营养值为空；
6. 下拉中文值已映射为稳定英文枚举；
7. 通过学校部门及专业人员审核；
8. 另行获得创建数据库和导入数据的明确授权。
